## Fast Planner migration

- Third-party source: [JackJu-HIT/Fast-Planner-2D-ROS2](https://github.com/JackJu-HIT/Fast-Planner-2D-ROS2), pinned `9ed668e9d7f47292b7256a1ee539f0164bf664f0`, vendored under `tb3_nav_ws/src/third_party/Fast-Planner-2D-ROS2/` with the existing integration fixes. Root and package MIT license files are retained. This is not the official HKUST Fast-Planner and is not claimed to reproduce its paper.
- `UPSTREAM.md`, `upstream-integration.patch` and `MIGRATION_SHA256.json` retain provenance, the tracked upstream delta and the source import snapshot. The patch is already applied; the old source workspace is not a build or runtime dependency.
- `tb3_nav_ws/src/fast_planner_nav2/` is the existing local Apache-2.0 Nav2 adapter, migrated with its tests. The two `config/2d/nav2_*.yaml` files are copied unchanged from the previous local integration; their Nav2 Humble baseline comes from `nav2_bringup`.
- `gazebo_building_editor_models/` contains user-supplied building resources, not downloaded TurtleBot3 assets. Preserve the supplied files and check their authorship/permission before public redistribution; no license is inferred for them.

The included example PCD was produced in the publicly available TurtleBot3 Gazebo simulation world using this experimental stack. It is intended as demonstration data, not proof of safe navigability, robot-level collision safety, or performance on real sensors.
